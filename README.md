# 弯曲角度分类：单文件训练与绘图Notebook

`bend_angle_ml.ipynb`包含21个分类模型、Optuna调参、嵌套交叉验证、完整指标、原模板绘图和全模型SHAP。代码和输入数据都在Notebook中，不依赖原项目目录或其他本地Python脚本。

## 使用

1. 准备Python 3.11，安装依赖：

   ```bash
   python -m pip install -r requirements.txt
   ```

2. 在Jupyter或VS Code中打开`bend_angle_ml.ipynb`，选择安装好依赖的Python内核。
3. 确认运行环境安装了Arial；也可在首个配置单元设置`FONT_DIRECTORY`，指定自己的字体目录。
4. 首次建议将配置中的`PROFILE`从`"full"`改为`"smoke"`，重启内核后从头运行全部单元。
5. 需要正式训练时，将`PROFILE`改回`"full"`，再从头运行。

单独下载Notebook时，也可先运行数据准备单元，由它生成`bend_angle_reproduction/requirements.txt`，再按提示安装依赖。

## 配置

| 配置 | 最终搜索/模型 | 每个外层训练子集的搜索 | 用途 |
|---|---:|---:|---|
| `smoke` | 5次 | 1次 | 验证代码、数据与图形流程，采用较小模型 |
| `quick` | 15次 | 3次 | 小预算探索 |
| `full` | 100次 | 20次 | 正式训练预算 |

随机种子为42。正式配置请求最多5折交叉验证，实际折数按每类可用样本/事件数自动调整，并写入运行记录。默认输入下，周期分组方案通常为外层3折、嵌套内层2折、最终内层3折；不能将请求折数当作实际执行折数。

`RUN_MODE="train_and_plot"`完成训练并绘图。已有本Notebook生成的同配置产物时，可将其改为`"saved_results"`重新绘图。它不会从原作者电脑读取旧模型。

`RESUME=True`允许继续已有Optuna搜索。若需要新的独立运行，可指定一个新的`OUTPUT_DIRECTORY`。中断后恢复的采样序列不保证与一次连续运行逐项相同。

## 数据与验证边界

- Notebook内置196个窗口及带采样时间、来源行号和事件标识的NPZ，来自28个弯曲—回位事件、5个目标角度类别。
- 正式16维输入是13个原始响应点，加窗口峰值、时间加权均值和时间加权RMS。Notebook独立复核三个统计量的计算结果。
- 同一事件的7个窗口高度重叠，不能作为7个独立实验样本。
- 周期分组方案冻结完整事件作为测试集；随机窗口方案作为对照，记录其共享事件和共享原始采样点的情况。
- 中位数填补、标准化和概率校准都在相应训练范围内拟合。模型选择以训练侧的外层宏F1为依据，不按测试集表现排名。
- 当前记录不构成跨器件、跨日期或跨材料批次验证。SHAP归因不等同于材料机制的因果证据。

## 绘图

保留原绘图模板及来源哈希，执行时记录数据适配和明确的代码替换。包括：

- 各模型的百分比混淆矩阵、分类ROC、外层折ROC；
- Optuna历史、参数重要性、二维和三维搜索图；
- 分类指标雷达图、极坐标图；
- 全21模型的SHAP组合图，支持树交互解释的模型另输出类别交互网络；
- 三个模型家族的混淆矩阵组图、九模型混淆矩阵/ROC及前三模型SHAP组图。

混淆矩阵按真实类别逐行归一化，每行未四舍五入前合计100%，显示一位小数。对角线表示该类别正确分类率（召回率）。原配色、类别顺序和版式保留。

所有图输出SVG/PDF，使用Arial，并保留可编辑文字。Notebook为SVG增加文字类别标记，并写出`按类别统一调整文字.jsx`，供用户在Illustrator中手动选择或修改同类文字。Notebook本身不调用Illustrator或computer-use。

Taylor模板作为可选角度误差辅助诊断保留，默认`ENABLE_TAYLOR=False`。它不作为分类模型排名依据。

参数重要性等图在试验目标值没有变化、无法估计重要性时会记录为未生成，不填造数值。SHAP输出尺度随解释器而异，请查看每个模型的说明；不同输出尺度的绝对SHAP值不能直接比较。

## 输出与上传

产物保存在当前工作目录的`bend_angle_reproduction/`中。主要包括：

- `model_comparison.csv`与完整逐类指标；
- 各模型的参数、训练记录、保存模型及冻结预测；
- `figures/original_templates/`中的单图；
- `figures/paper_groups/`中的组图；
- `all_models_shap/`中的解释张量、背景样本索引及加和一致性检查。

本仓库包含一个清洁源码Notebook，历史计算输出已清空。字体文件、保存模型和本机缓存不放入上传包；`.gitignore`默认排除生成产物。原模板文件名与哈希见`sources_manifest.json`。

## 验证记录

最终打包时的实际执行范围记录在`validation_status.json`。`smoke`通过仅表示整合后的全流程可执行，不能代替正式100次搜索的论文结果。
